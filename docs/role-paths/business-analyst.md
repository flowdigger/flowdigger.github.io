# Business Analyst Path

## Purpose

Help analysts answer impact and traceability questions with lineage views.

## When to use

Use this path when you need trusted flow explanations for requirements, controls, or change analysis.

## Inputs

- Business terms
- Data elements
- Report or process scope

## Steps

1. Read [Data lineage in legacy systems](../core-concepts/data-lineage-basics.md).
2. Read [Lineage architecture map](../lineage/index.md).
3. Read [Legacy system lineage story](../case-stories/legacy-system-lineage-story.md).
4. Use [Validate lineage quality](../how-to/validate-lineage-quality.md) to review evidence confidence.
5. Use [Glossary and acronyms](../reference/glossary.md) to standardize terms.

## Output

You can explain upstream and downstream impact with shared terminology.
