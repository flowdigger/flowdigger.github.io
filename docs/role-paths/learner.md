# Learner Path

## Purpose

Help new readers learn lineage concepts before deep technical material.

## When to use

Use this path when you are new to data lineage or to Flowdigger documents.

## Inputs

- Curiosity
- One system example from your environment

## Steps

1. Read [Data lineage in legacy systems](../core-concepts/data-lineage-basics.md).
2. Read [Glossary and acronyms](../reference/glossary.md).
3. Read [Storyline and learning path](../core-concepts/storyline.md).
4. Read [Legacy system lineage story](../case-stories/legacy-system-lineage-story.md).
5. Explore one source paper from [Reference](../xir-metadata-lineage-papers/README.md).

## Output

You get clear baseline understanding and safe next steps.
