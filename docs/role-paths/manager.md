# Manager Path

## Purpose

Help managers evaluate lineage capability, delivery risk, and governance readiness.

## When to use

Use this path when you plan roadmap, budget, controls, or modernization decisions.

## Inputs

- Delivery goals
- Risk and compliance goals
- Legacy system scope

## Steps

1. Read [Storyline and learning path](../core-concepts/storyline.md).
2. Read [Lineage architecture map](../lineage/index.md).
3. Read [Legacy system lineage story](../case-stories/legacy-system-lineage-story.md).
4. Review [Validate lineage quality](../how-to/validate-lineage-quality.md) for success criteria.
5. Review source papers in [Reference](../xir-metadata-lineage-papers/README.md) when you need decision depth.

## Output

You can decide scope, priorities, and quality targets with less ambiguity.
