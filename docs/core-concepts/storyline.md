# Storyline and Learning Path

## Purpose

Provide one narrative from problem to operational value.

## Storyline

1. Legacy system contains business-critical data logic.
2. Teams need trusted lineage for change, control, and modernization.
3. Flowdigger collects technical evidence from system artifacts.
4. Flowdigger derives lineage facts with deterministic transformations.
5. Teams validate quality with explicit checks.
6. Teams publish role-specific views for decision and action.

## Why this order

This order reduces ambiguity. Each step has clear input and output.
