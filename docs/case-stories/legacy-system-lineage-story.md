# Legacy System Lineage Story

## Purpose

Show practical use of lineage method in one legacy domain.

## Scenario

Team must explain how risk report field is calculated across old ETL and database jobs.

## Method

1. Collect SQL and mapping logic.
2. Normalize logic into common representation.
3. Derive lineage links.
4. Validate with business analyst and engineer.
5. Publish result for change and control workflows.

## Result

- Faster impact analysis
- Less ambiguity during change reviews
- Better traceability for governance teams
